NCBAHM Exam Simulator

Live Open source

A practice-exam platform for the three board modules acupuncturists sit for national certification. The interesting part is not the quiz UI. It is the content pipeline: every question is machine-validated, then answered blind by an independent solver before it can enter an exam.

  • 1,500 original items across three modules, assembled against the official 2026 blueprint weights for each domain and subdomain.
  • Staged validation with explicit statuses: draft, AI-reviewed, human-approved. Nothing is labeled professionally validated unless a named reviewer is recorded on it.
  • Fidelity mode follows the real exam's rules: forward-only, answers lock, nothing revealed until submission. Scores are raw percentages; it never invents a scaled score or a pass prediction.
  • Fully client-side. Performance history lives in SQLite in the browser (sql.js on IndexedDB), with SM-2 spaced review and weakness targeting on top.
  • CI runs typecheck, tests, and a bank audit (coverage, duplicates, ambiguity) before every deploy.
  • TypeScript
  • Vite
  • sql.js
  • Vitest
  • GitHub Actions

Oregon eviction court-records pipeline

Open source 2021–2022

Research data engineering for Portland State University's eviction research. Oregon publishes eviction filings as individual court records, not as a dataset. This pipeline turned them into one.

  • Scrapy spiders crawl the state court system's eviction cases into a dated PostgreSQL database; R pulls the tables and builds the analysis flat file. One command runs all four stages.
  • Daily and weekly variants kept the data current while eviction policy was changing month to month.
  • Published outputs: a ranking of the highest-volume filers and a block-group map.
  • Python
  • Scrapy
  • PostgreSQL
  • R
  • Shiny
  • QGIS
